Make it visible

Sizes and distances use arbitrary model units. The eclipse buttons use the current sizes, tilt, and spacing. Position sliders pause the animation; the day count is model time, not a calendar date.

The Sun contains a point light. Earth and Moon cast shadows, with optional fill light on their dark sides. The Moon’s orbit defaults to a 5.145° tilt; Earth’s axis is tilted 23.44°. Circular orbits and a fixed line of nodes simplify the motion. Observers sit at 45° N; sunrise/sunset use the geometric, point-light terminator without refraction. Eclipse jumps describe this exaggerated, point-light model, not real-world predictions. Solar-angle reference. Built with assistance from OpenAI Codex.
